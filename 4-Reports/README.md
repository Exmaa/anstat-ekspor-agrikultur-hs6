# Folder 4-Reports

Direktori ini memuat seluruh dokumen laporan hasil penelitian, naskah komputasi Quarto/RMarkdown, dan materi visualisasi infografis.

## Keluaran Deliverables

1. **Laporan Penelitian Komprehensif (Format PDF)**:
   - Disusun menggunakan Quarto CLI dengan tata letak Typst / LaTeX.
   - Memuat latar belakang, perumusan masalah, landasan teori metode ANSTAT IPB, audit data, hasil estimasi OLS, tabel diagnostik Gauss-Markov, dan pembahasan sintesis komparatif.

2. **Infografis Visual (Format PNG, Ukuran A3)**:
   - Visualisasi hasil riset resolusi tinggi berstandar publikasi dalam ukuran A3.
   - Memuat alur komparasi 3 komoditas HS-6, pergeseran rezim tarif dan Selat Hormuz, matriks VIF & diagnostik sisaan, serta ringkasan elastisitas ekonomi.
